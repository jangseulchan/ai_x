📄 /api/flood_map API
기준: 최근 1시간 데이터 평균 (precip, humidity, month, warning_factor)
산식: (precip * 0.4 + humidity * 0.3 + season * 0.3) * 특보 가중치
반환: { '강남구': 78.3, '서초구': 62.1, ... }

위험도 가중치 적용: 특보 발령시 위험도 2.5배 증가
호우경보 → 위험도 2.5배
호우주의보 → 위험도 1.8배  
태풍 → 위험도 3.0배

위험도 = (고품질_강수량 * 0.4 + 습도 * 0.3 + 계절 * 0.3) * 특보_가중치.

기상특보로 정부 공식 위험도 반영


*
위험도 = (강수량 * 0.4 + 습도 * 0.3 + 계절계수 * 0.3) × 특보 가중치
계절계수: 0.3 (건기) ~ 1.0 (장마철 6~9월) → 6~9월=1, 그 외=0.3

특보 가중치:
호우경보: ×2.5
호우주의보: ×1.8
태풍: ×3.0
없음: ×1.0
