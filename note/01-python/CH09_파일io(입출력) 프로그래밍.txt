3절. CSV형식 파일 읽기/쓰기

3.1 reader
reader() 함수는 지정된 파일에서 분리된 문자열로 데이터를 읽기 위한
객체를 반환

3.2 writer
파일에 구분자로 연결된 문자열 데이터를 저장하는 객체를 반환

3.3 DictReader
DictReader 클래스는 reader 와 비슷하게 동작하지만 각 행의 정보를 OrderedDict 객체로 반환
CSV 파일에 각 열들의 이름 메타정보 을 지정해서 데이터를 딕셔너리 형식으로 불러옴

3.4 DictWriter
DictWriter 클래스는 딕셔너리 데이터 행 별로 CSV 파일에 저장

4절. JSON 데이터 저장하고 불러오기(dump, load)

4.1 dump(파일 출력)
dump() 함수는 파이썬 객체를 JSON 형식으로 변환

4.2 load(파일 입력)
load() 함수는 JSON 형식 데이터를 파이썬 객체로 변환

json파일 -> 딕셔너리리스트(기본)
          ↓
json파일 -> 객체리스트
